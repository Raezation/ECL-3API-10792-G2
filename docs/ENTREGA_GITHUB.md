Num computador com GitHub CLI, autentique-se na sua própria conta e obtenha uma cópia:

```bash
gh auth login
gh repo clone Raezation/ECL-3API-10792-G2
cd ECL-3API-10792-G2
```

A instalação e execução seguem o README. Para contribuir, use este clone do GitHub. O ZIP disponibilizado não contém uma pasta .git; contém os ficheiros do projeto e o arquivo do histórico original indicado a seguir.

## Trabalho de Jorge e Israel

Cada formando deve configurar a sua própria identidade Git e fazer alterações reais que compreenda. Por exemplo, um pode melhorar a pesquisa e explicar os respetivos testes; o outro pode acrescentar um filtro de empréstimos e os seus testes. São propostas, não contribuições já realizadas. Depois da revisão, atualizem a secção de organização do relatório com tarefas e hashes reais.

Não mudem o autor de commits gerados pela IA para simular participação. Não alterem datas para inventar um desenvolvimento prolongado. Antes da entrega, confirmem a execução a partir de um clone limpo, a presença do PDF em /docs e a legibilidade das capturas.
